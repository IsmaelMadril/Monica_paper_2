# Preserved inputs

`baseline_2026-10-23/` contains byte-for-byte local copies of the supplied inputs.
Treat these snapshots as immutable. Do not clean, recode or overwrite them.
Their SHA-256 hashes and original paths are recorded in
`provenance/input_manifest.csv`. National annual source files have not yet been
provided; the existing SAV/workbooks must not be labelled original INEC extracts.

Snapshots and datasets are excluded from Git. Back them up separately with the
manifest; a Git checkout alone cannot reproduce the analysis without these files.
